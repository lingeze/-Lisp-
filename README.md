# Mini-Lisp

本项目在基础功能上主要进行了用户体验的完善，补全了R^7^RS标准内 Delayed evaluation 部分的语法。

## 使用介绍

### 文件模式

```bash
mini_lisp <file.scm>
```

### REPL 模式

```bash
mini_lisp              # 直接启动
mini_lisp --repl       # 强制 REPL（即使给了文件也不执行）
mini_lisp -r           # 同上
```

## REPL 功能体验改善
相关功能改善基于replxx第三方库实现。

| 功能                     | 快捷键          | 说明                                                                        |
| ------------------------ | --------------- | --------------------------------------------------------------------------- |
| **Tab 补全**       | `Tab`         | 根据当前环境中的符号名自动补全，包括自己define的符号名                                              |
| **多行输入**       | `Enter`       | 当表达式括号未闭合时，Enter 插入换行而非提交；括号全部闭合后 Enter 提交求值 |
| **跳转匹配括号**   | `Alt+m`          | 光标在 `(` 或 `)` 上时，高亮匹配的括号，按 F2 跳转到配对的括号位置                            |
| **跳转表达式起始** | `Alt+a`   | 从光标位置向上查找最近的未闭合 `(`，跳转过去                              |
| **跳转表达式结尾** | `Alt+d`    | 从光标位置查找当前表达式的匹配 `)`，跳转到其后                            |
| **历史记录**       | `↑` / `↓` | 浏览历史输入，历史文件保存在 `~/.mini_lisp_history`                       |
| **语法高亮**       | —              | 自动着色（见下方色表）                                                      |

### 语法高亮色表

| 元素                                                                                                              | 颜色      |
| ----------------------------------------------------------------------------------------------------------------- | --------- |
| 特殊形式（`define`, `lambda`, `if`, `cond`, `let`, `begin`, `quote`, `and`, `or`, `else` 等） | 粗体品红  |
| 内置过程（`+`, `-`, `*`, `/`, `car`, `cdr`, `cons`, `map` 等）                                    | 粗体蓝    |
| 用户定义过程                                                                                                      | 粗体蓝    |
| 字符串 `"..."`                                                                                                  | 绿        |
| 注释 `;...`                                                                                                     | 灰        |
| 数字                                                                                                              | 黄        |
| 布尔 `#t` / `#f`                                                                                              | 品红      |
| 引号 `'` / `` ` `` / `,`                                                                                      | 品红      |
| 不匹配的 `)`                                                                                                    | 红+下划线 |
## 新语法
本项目根据R^7^RS标准，实现了`delay`、`force`、`delay-force`、`promise?`、`make-promise`的语法。
